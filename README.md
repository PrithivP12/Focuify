# Focuify projects

This repository contains two versions of Focuify:

- [`focuify`](focuify/) is the standalone Chrome extension. Load this folder as an unpacked extension.
- [`focuify_teacher`](focuify_teacher/) is the classroom version from commit `0b1d360`. It includes the student extension, teacher dashboard, server, tests, and build script.

Each folder has its own README with setup instructions.
